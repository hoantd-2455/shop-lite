# Module 1: HTML, CSS & Tailwind

**Thời lượng:** 3 ngày

## Trọng tâm

Tập trung vào cấu trúc HTML semantic và CSS layout (Flexbox, Grid, responsive). Đây là phần có thể ngốn thời gian bất ngờ với người đã có nền lập trình, vì layout là tư duy thị giác chứ không chỉ là logic. Đừng xem nhẹ.

## Đóng góp vào ShopLite

Xây toàn bộ giao diện tĩnh (chưa có JavaScript): trang danh sách sản phẩm, trang chi tiết sản phẩm và trang giỏ hàng. Giao diện cần responsive trên cả mobile lẫn desktop.

## Mục tiêu cuối module

- Viết HTML semantic và đúng accessibility cơ bản (`alt`, `label`, thứ tự heading).
- Dựng layout thành thạo bằng Flexbox và Grid, không dùng `float`.
- Làm responsive với media query, `clamp()` và các đơn vị linh hoạt.
- Làm quen Tailwind CSS theo hướng utility-first và hiểu cách nó ánh xạ sang CSS gốc.
- Có giao diện ShopLite tĩnh, đẹp ở mọi kích thước màn hình.
